# Detailed Comparison Results between LNPS and Other Strategies

This directory contains supplementary materials for Section 4 (Experiments) of the paper:

> H. Nabeshima, M. Banbara, T. Schaub, and T. Soh: The Magnificent ASP-based Nurse Scheduling System at the University of Yamanashi Hospital, submitted to ICLP 2025.

For reproducibility and further analysis, we include all relevant data files, evaluation and visualization scripts. Visualized results are available on [GitHub Pages](https://nabesima.github.io/yamanashi-nsp-comparison/).
